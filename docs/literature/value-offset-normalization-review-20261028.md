# Value offsets, PopArt and average-reward SAC

These are three different interventions. None currently establishes a tenfold StackCube gain, and this note admits no algorithm implementation or robot experiment.

**Discounted reward centering.** [Naik, Wan, Tomar and Sutton (2024)](https://arxiv.org/html/2405.09999) retain discounted Bellman learning while subtracting an estimated reward rate. For an ergodic continuing policy, the value decomposes into a state-independent term proportional to `1/(1−gamma)` and relative values. Removing the former can help approximation focus on action differences. Their evidence includes tabular, linear and neural Q-learning on continuing tasks, with stronger benefits as gamma approaches 1. Simple reward averaging tracks the behavior policy; action importance ratios alone do not correct the state-distribution mismatch. Their value-based estimator instead couples reward-rate updates to TD errors. They explicitly caution that naive episodic centering can change the problem. This is evidence for conditioning, not a demonstrated neural-SAC robot speedup. Reading: Sections 1–5, including off-policy equations and limitations.

**What disappears, algebraically?** The following is our derivation, not a robot finding. With fixed policy and fixed subtracted reward `b`, the centered Bellman operator has the same derivative `gamma*P`. A constant error still contracts by gamma; idealized instantaneous fitting plus target EMA gives `1−tau*(1−gamma)`. Fixed centering changes the forcing/fixed point, **not this eigenvalue**. An oracle offset can avoid exciting the slow mode from initialization; fresh constant perturbations remain slow. An adaptive estimator/projection can change the dynamics: for the scalar updates `q+=a*delta`, `b+=eta*a*delta`, with `delta=r−b−(1−gamma)*q`, the residual contracts by `1−a*((1−gamma)+eta)`. That example has coupled coordinates and a family of fixed points; it is not a neural/Polyak convergence guarantee.

**Exact SAC coordinates.** Write online and target values as `Q_o=C_o+q_o`, `Q_t=C_t+q_t`, and let `m` be the bootstrap mask. The residual target is

`y_q = r + gamma*m*(C_t + q_t − alpha*logpi) − C_o`.

Only shared `C` and `m=1` yield `r−(1−gamma)*C+gamma*(q_t−alpha*logpi)`. Changing `C` requires shifting residual heads to preserve represented values, with explicit target-coordinate bookkeeping. Constant `C` has zero actor action-gradient when detached; this does not imply unchanged critic optimization. Fixed reward shifts preserve preferences for nonterminating discounted returns or fixed action-independent horizons. Variable stopping requires terminal corrections; arbitrary reward subtraction is not automatically invariant. Soft entropy also contributes an offset: environmental reward centering alone need not remove it.

**Output-preserving normalization.** [van Hasselt et al., PopArt (2016)](https://papers.neurips.cc/paper_files/paper/2016/file/5227b6aaf294f5f027273aebf16015f2-Paper.pdf) represent unnormalized output as `Q=sigma*(W*h+b)+mu`. Updating statistics uses `W'=sigma/sigma'*W`, `b'=(sigma*b+mu−mu')/sigma'` to preserve every output, then optimizes normalized targets. This changes update conditioning without clipping the reward objective. It does not inherently deflate a Bellman eigenmode. In SAC, actor/backup computations must use consistent unnormalized values: using normalized Q against unchanged alpha changes their tradeoff. Target heads/statistics and optimizer treatment require explicit design; output preservation alone does not guarantee future Adam-trajectory equivalence. The paper studies regression and 57 Atari games, including mixed game-level gains/losses after 200M frames, not tenfold manipulation efficiency. Reading: Proposition 1, Algorithm 1, Sections 3–4.

**Average-reward objective.** [Hisaki and Ono, RVI-SAC (2024)](https://arxiv.org/html/2408.01972) remove discounting and learn differential soft values for long-run average reward plus entropy. Its target is effectively `r_hat−xi+min(Q_target)−alpha*logpi`; `xi` smooths a minibatch estimate of entropy-augmented target values. This anchors the otherwise free additive value coordinate. The paper identifies instability without the delayed estimate. Terminating tasks become reset transitions with an adaptive reset cost, an additional reset critic and constraint. Thus it changes objective and training dynamics; it is not free discounted centering. Six MuJoCo tasks/ten seeds show competitive step-based results, with HalfCheetah an exception to matching/beating best-discount SAC. This does not establish equal-compute StackCube improvement. Frozen benchmark evaluation would remain unchanged; reset semantics would still be a separately disclosed training intervention. Reading: Sections 2–4 and Appendix B equations 17–25.

**Necessary cheap gate before implementation:** a separately reviewed CPU fixed-policy example should expose constant and relative errors independently, inject constant perturbations, and check coordinate/terminal/target consistency and action gradients across offset changes. Then test identical replay rows with shifted targets, reporting relative-action error, actual updates and time—not merely smaller Q-loss. A speed claim must survive wrong reward-rate estimates and entropy offsets. Failure to improve relative values cheaply is a reason to stop; no robot run or new method is authorized here.
