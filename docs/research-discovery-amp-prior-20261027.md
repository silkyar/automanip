# Prior-assisted manipulation learning: source ready, small pilot only

This is a **separate prior-assisted track** authorized by the user. A student
starts from random weights, learns BC from actions generated by our own teacher,
and may then receive an AMP-style transition reward during PPO. Teacher training,
every demo-generation rollout, BC computation and student RL computation must all
be counted. No teacher weights are copied into a student. No pure-from-scratch,
novelty or robotic sample-efficiency improvement is claimed.

The source and CPU dataflow work are complete. No cloud upload or paid launch was
performed by this research agent. Further uploads remain subject to the owner's
standing approval process; there is no alternative deployment workaround.

## Mechanism and primary sources

[AMP](https://xbpeng.github.io/projects/AMP/) and its
[primary paper](https://arxiv.org/abs/2104.02180) learn a discriminator over
consecutive motion states, use learner replay and an expert-side gradient penalty,
and supply a bounded style reward to RL. Our prototype uses the same least-squares
labels (+1 expert, −1 learner), penalty convention and bounded score-to-reward
mapping. It uses the existing full state48 followed by next state48, rather than
AMP's character-specific, task-independent kinematic features. This is an
**AMP-style, task-specific adversarial transition prior**. It can recognize state
occupancy without learning useful temporal composition.

[GAIL](https://arxiv.org/abs/1606.03476) already establishes adversarial imitation.
The first question here is whether successful-task data helps student learning
and whether adversarial reward adds value beyond action cloning, not whether the
combination is novel.

Inspected the official ManiSkill BC implementation at commit
`6226567ce326625fa6eacf9aeb3f4008e4339f7e`. Its action-MSE training is the
conventional BC anchor. Exact source SHA256:
`dc7b1f3a55ce7c5dcf79a627105e3689e0e5a2240440e6e24d439632867412c3`.
Source, README and provenance are preserved in
`research/discovery/upstream/bc-v3.0.0b21/`. Our BC actor changes the official
two-ReLU-hidden-layer network to the existing safe three-tanh-layer architecture.
We keep horizon 50 and the fixed controller; the upstream README's suggestion to
increase imitation horizons is not adopted.

`source-receipt.json` beside these files records the module hashes. All frozen v1
sources remain unchanged. Removing `DISCOVERY_ASSIST` blocks restores the exact
owner-provided public PPO base, SHA256
`cd7ee5704baa451c0fb616140be2b8efc1830ae1dd3d355fc7d83e435b411082`.
The ordinary Agent class, critic targets, Gaussian interface, optimizer/std audit
tags and actor/critic state_dict schema remain unchanged. The discriminator and
its optimizer/replay stay outside Agent serialization and never enter evaluation.

Both RL arms require the same BC student artifact, BC provenance report and demo
dataset. They reject native `--checkpoint` inputs, preventing accidental teacher
weight loading. The initializer verifies a random-student BC report, matching
dataset/actor digests and production eligibility. It changes only actor-mean
weights; the ordinary randomly initialized critic and global std remain intact.

Only the learner reward buffer receives
`r_train = r_stock_task + .25*r_prior`. Environment rewards, task success flags,
episode horizon, observations/actions and protected scoring are unchanged.
Style rewards are detached and bounded in [0,1]. They are computed with a fixed
discriminator during each rollout. The discriminator then receives 32 Adam updates
of 256 expert and 256 learner pairs per rollout, with least-squares regression and
expert-side gradient penalty coefficient 10. Fixed demo normalization uses only
training episodes. Learner replay capacity is 100,000 transitions and retains all
learner outcomes. No success label or action is a discriminator input.

## Data contract and production pins

`trajectories.npz` uses numeric arrays, read with `allow_pickle=False`:

```text
observations         float32 [episodes,51,48]
actions              float32 [episodes,50,8]  executed clipped actions
task_rewards         float32 [episodes,50]
final_success        bool    [episodes]
public_training_seed int64   [episodes]
```

`dataset.json` binds the file digest, declared public-training source, software
versions, teacher artifact and prefix costs, all complete successes/failures,
actual generation steps, reset calls and incomplete work. The collector disables
auto-reset, retaining the real final state. The PPO hook instead validates and
uses the wrapper's pre-reset `final_observation` at automatic resets; reset jumps
never become imitation transitions.

Complete failed teacher episodes remain in the raw dataset. Success selection
for demonstrations is explicit and labeled. The selected successful episodes
are split 90/10 by episode, not by correlated rows. BC and AMP use the same
training subset; public demo validation is separate from protected scoring.

Default production loading and collection require the declared Linux/GPU pins:
ManiSkill 3.0.0b21, SAPIEN 3.0.0b1, torch 2.6.0+cu124, NumPy 1.26.4 and
gymnasium 0.29.1, with `physx_cuda`. The explicit local CPU flow mode instead
requires dev-SAPIEN 3.0.4.dev20261009+7dba23f1, `physx_cpu`, a smoke-only purpose and
`comparison_eligible=false`. Production RL payloads reject these CPU datasets
and their BC reports. These guards were not relaxed to obtain a result.

## CPU evidence

Nine focused tests pass: safe actor numeric parity/clipping, episode splitting
without reset jumps, strict CPU-source opt-in, correct final successors, the
least-squares/gradient-penalty calculation, reward bounds/detachment/private RNG,
collector bookkeeping, exact removable patches, and embedded-runtime initialization
with unchanged critic/std/serialization.

The six-seed synthetic component gate completed in 1.64 seconds. Held-out BC action
MSE decreased from .096–.112 to .00160–.00190. The discriminator assigned expert
transition style .966–.968 versus .242–.303 for opposite transitions with matching
state marginals. This verifies regression/classification components, not robotic
learning. Record: `research/discovery/amp-cpu-gate-v1.json`.

The owner separately supplied an explicitly non-benchmark Mac CPU dataflow dataset:
256 fresh training episodes/12,800 transitions, 247 successes and 9 failures retained,
14.008 seconds generation. Teacher: our 50M constant seed1 policy, 127/128 development
success, not a three-seed-confirmed teacher claim. Its exact training prefix is
49,971,200 transitions/2295.4083 trainer seconds. No protected teacher weights were
read by this research agent.

The owner ran the frozen BC CLI locally: 5000 updates/5.12M demo minibatch rows,
11.7685 seconds, 223 successful training episodes and 24 successful demo-validation
episodes. Held-out action MSE was .0101664. The student collected no environment
transitions during BC. Safe actor SHA256:
`c13416787d05347ccc1e92ad95d48a1bb649b6d7a83e883823600db253b15a53`.
The owner's paired local training-seed check reported random 0/64, BC 21/64 and
teacher 61/64. This is dataflow evidence under different physics software, not a
benchmark. Its gap motivates checking coverage and closed-loop error; no cause
is established by action MSE or success counts alone.

## Real-transition discriminator probe

The owner supplied another fresh public-training collection: 64 random-policy and
64 BC-policy complete CPU episodes, 3200 transitions each, with all failures retained.
BC had 19 final successes; random had 0. The bounded probe trained only on 52 BC
episodes as negatives and 223 teacher-success episodes as positives; 12 BC and 24
teacher episodes were held out. Random-policy trajectories were held-out stress,
never training negatives. It ran 200 discriminator updates in 0.90 seconds and made
no new simulator query. Record:
`research/discovery/amp-local-discriminator-probe-v1.json`.

| Held-out/source condition | Mean style reward |
|---|---:|
| Real teacher transitions | .82555 |
| Real BC transitions | .63298 |
| Teacher successors shifted 25 steps within their episodes | .80745 |
| Unseen random-policy transitions | .71188 |

Teacher-minus-BC style gap .19257 and balanced sign accuracy .6875 pass the declared
**dataflow/signal** gate. The small real-versus-shifted gap .01811 does not establish
substantial temporal-motion modeling. High style on unseen random transitions
despite zero task successes shows that discriminator confidence is not a success
guarantee. Outcome-stratified holdout scores also have very small sample counts.
Do not infer causal motion learning, robust reward generalization or sample
efficiency from this classifier separation.

Recommendation: **small paired production pilot only**, after upload approval.
Keep BC-only as the offline baseline, compare the identical BC warm start with
ordinary PPO against PPO plus the prior, and log task/prior rewards separately.
An AMP gain must survive a competent BC+PPO control; if ordinary fine-tuning loses
the BC policy, investigate that control before claiming an adversarial advantage.
No large campaign is justified by this CPU probe.

## Exact handoff and accounting

Stage only the three candidate modules for collection/BC, or the self-contained
RL payload, alongside owner-approved public data. No evaluator, private seeds,
credentials or teacher weights belong in the student mount. The existing trusted
launcher handles internal-evaluation disabling, absolute deadlines/hard stops,
safe policy exports, protected scoring and the shared overnight budget.

  --output /workspace/public-demos --seed-start 90180000 \
  --episodes 512 --num-envs 64 --max-seconds 120 \
  --teacher-prefix-transitions 49971200 \
  --teacher-prefix-trainer-seconds 2295.408300588

  --dataset /workspace/public-demos --output /workspace/bc-student \
  --seed 1 --updates 5000 --batch-size 1024 --max-seconds 120 --device cuda

confirmation campaign is implied. Evaluate BC-only and matched student checkpoints
on common development cadence; independently repeat promising training seeds

Report marginal student transitions and total `teacher_prefix + demo_generation +
